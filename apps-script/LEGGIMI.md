# Codice Apps Script del foglio Priamus

Questa cartella contiene il codice del progetto Apps Script collegato al foglio Priamus.
Non si incolla più a mano: l'**Aggiornatore Priamus** (cartella `aggiornatore/`) legge
questi file e li installa nel foglio, salvando prima una copia su Drive.

- `.gs` → file di script, `.html` → file HTML, `appsscript.json` → manifest
- Password e segreti NON stanno qui (il repository è pubblico): sono nelle
  Proprietà script del progetto (`API_SEGRETO`, `PASSWORD_ADMIN`).
